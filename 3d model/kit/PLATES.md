plates**. Each plate's preview is embedded in the file as
`Metadata/plate_N.png` (also `plate_N_small.png`); the per-plate contents
below are a guide, not a substitute for the preview — Bambu Studio shows the
exact arrangement.

Print in plate order (structural first, per BUILD.md). If a plate looks
under-filled, group it with an adjacent plate manually — the kit favors
correct grouping over strict plate count.
